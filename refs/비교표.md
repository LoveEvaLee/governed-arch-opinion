## 공통 패턴

출처가 달라도 반복되는 것.

**ETL · 오케스트레이션 (2026-10-11)**

- **리니지는 OpenLineage로 모인다.** Glue(SageMaker Catalog 수집), Airflow 직접 운영(OpenLineage 프로바이더), Cloud Composer(Data Lineage API)가 모두 OpenLineage 이벤트를 쓴다. dbt는 자체 Discovery API · 컬럼 리니지(Enterprise)로 낸다
- **에이전트 연계 수단으로 MCP 서버가 나와 있다.** Glue · Step Functions(AWS Labs 오픈소스), dbt(공식), Cloud Composer(공식 원격 서버, GA 2026-08-25), Airflow 직접 운영(벤더 Astronomer 오픈소스). MWAA는 AWS 공식 MCP 저장소에 없다(2026-10-11 확인) — REST API(InvokeRestApi)로 호출한다
- **버전 수명이 대체로 12개월 단위다.** MWAA 버전당 최소 12개월, Composer Gen 3 빌드 12개월, dbt 마이너 1년. Glue는 구성요소의 커뮤니티 LTS에 맞춘다. Airflow 3의 EOL은 TBD
- **고객 관리형 키를 지원한다.** MWAA · Step Functions(KMS), Cloud Composer(CMEK). Glue의 키 근거는 이번에 모으지 않았다

## 표기 차이

같은 것을 출처마다 다르게 부르는 자리. `layouts/표기규칙.md`가 이 목록을 보고 정해진다.

| 같은 것 | 부르는 이름 | 출처 |
|---|---|---|
| GCP 관리형 Airflow | Cloud Composer ↔ Managed Service for Apache Airflow(2026-04-15 개명) | Composer 릴리스 노트 |
| Composer 세대 | Composer 1 / 2 / 3 ↔ Gen 1 / 2 / 3 | Composer 문서 |
| dbt 관리형 | dbt Cloud ↔ dbt platform | dbt 문서 |
| dbt 오픈소스 | dbt Core(v1) ↔ dbt-oss(v2). v2 기본 배포판 `dbt`는 독점 | dbt 라이선스 문서 |
| 지원 종료 단계 | Glue: EOS → EOL / MWAA: end of support / Airflow: Maintenance → Limited → EOL / dbt: active → critical / Composer: post-maintenance → end of life | 각 버전 정책 문서 |
| MWAA 실행 형태 | Provisioned 환경 ↔ MWAA Serverless | MWAA 요금 |

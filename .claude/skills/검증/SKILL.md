# ⑤ 검증

## 하는 일

1. ③ · ④의 출력과 운영사 설명에서 주장을 뽑는다 — 예: "도구를 통일하는 게 낫다", "이 구성이 비용이 싸다"
2. 주장마다 판정한다

| 판정 | 기준 |
|---|---|
| 사실 | 신뢰도 A·B 출처 또는 검산 가능한 산식으로 확인됨 |
| 근거 부족 | 확인할 출처·숫자가 없음 |
| 반박 | 반대 근거가 A·B 출처로 있음 |

3. 근거 부족인 주장마다 운영사에 던질 질문을 만든다
4. 비교표에 쓰인 출처마다 신뢰도 등급이 붙어 있는지 확인한다

## 우리 안도 공격한다 — 되돌리지 않는 판단

③이 만든 안을 ③이 검증하면 자기 편을 든다. ⑤는 운영사 안과 우리 안에 같은 기준을 적용한다.

## 판정까지만 한다

어느 안을 택할지는 사람이 정한다. ⑤는 판정 · 출처 · 질문까지만 낸다.

## 출력

- `out/<사례명>/검증.md` — 주장 / 판정 / 출처 / 비고
- `out/<사례명>/질문목록.md` — 협의에 들고 갈 질문

## 하지 않을 것

- 판정을 근거 없이 내기 — 확인 못 하면 "근거 부족"
- 결론 바꾸려고 출처 등급 올리기

## 현재 상태

뼈대만. 순서상 ③④ 다음.

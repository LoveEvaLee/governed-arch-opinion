## 공통 패턴

출처가 달라도 반복되는 것.

**ETL · 오케스트레이션 (2026-10-11)**

- **리니지는 OpenLineage로 모인다.** Glue(SageMaker Catalog 수집), Airflow 직접 운영(OpenLineage 프로바이더), Cloud Composer(Data Lineage API)가 모두 OpenLineage 이벤트를 쓴다. dbt는 자체 Discovery API · 컬럼 리니지(Enterprise)로 낸다
- **에이전트 연계 수단으로 MCP 서버가 나와 있다.** Glue · Step Functions(AWS Labs 오픈소스), dbt(공식), Cloud Composer(공식 원격 서버, GA 2026-08-25), Airflow 직접 운영(벤더 Astronomer 오픈소스). MWAA는 AWS 공식 MCP 저장소에 없다(2026-10-11 확인) — REST API(InvokeRestApi)로 호출한다
- **버전 수명이 대체로 12개월 단위다.** MWAA 버전당 최소 12개월, Composer Gen 3 빌드 12개월, dbt 마이너 1년. Glue는 구성요소의 커뮤니티 LTS에 맞춘다. Airflow 3의 EOL은 TBD
- **고객 관리형 키를 지원한다.** MWAA · Step Functions(KMS), Cloud Composer(CMEK). Glue의 키 근거는 이번에 모으지 않았다
- **관리 API 호출은 클라우드 감사 로그에 남는다.** Glue · Step Functions는 CloudTrail(근거 확인). 직접 운영 Airflow · dbt platform은 자체 감사 로그(Airflow는 Admin만 열람, dbt는 Enterprise 이상 · API로 내보내기)

**AI · 에이전트 플랫폼 (2026-10-11)**

- **관리형 플랫폼은 "런타임 + 게이트웨이 + 아이덴티티 + 메모리 + 관측" 묶음으로 수렴했다.** AgentCore와 Vertex AI(Agent Runtime)가 같은 구성을 갖고, 둘 다 LangGraph 등 오픈소스 프레임워크를 올릴 수 있다(AgentCore 근거 4, Vertex 근거 4)
- **MCP 게이트웨이가 도구 연계의 표준 자리가 됐다.** AgentCore Gateway, Vertex Agent Gateway, LiteLLM이 MCP 게이트웨이를 내놓고 도구 단위 권한 · 사용자 위임(OAuth 3LO)을 한다
- **과금은 vCPU-시간 + 메모리 GB-시간 + 호출 건수.** AgentCore · Vertex · LangSmith Deployment가 같은 틀이다
- **직접 운영 오픈소스(LiteLLM · vLLM)는 패치 부담이 크다.** 두 프로젝트 모두 2026년 3~10월에 원격 코드 실행 · SQL 인젝션 · 공급망 침해급 보안 공지가 있었다(LiteLLM 근거 9, vLLM 근거 3)

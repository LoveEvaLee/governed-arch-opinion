# 인프라 아키텍처 제안·검증 에이전트

외부 운영사가 그려온 인프라 구성도를 근거 없이 따라가지 않도록, 최신 동향을 근거로 우리 안을 내고 운영사 안과 비교·검증하는 에이전트 5개.
기준 구조는 AWS Control Tower 랜딩존. 특정 회사에 묶이지 않고, 회사 맥락만 갈아 끼우면 어디서나 쓴다.

## 에이전트 (.claude/skills/)

| | 이름 | 하는 일 |
|---|---|---|
| ① | 동향수집 | 영역별 동향·사례 수집, 출처·날짜·신뢰도(A~D) 표기 |
| ② | 맥락 | 회사 고정 구조·정책·가중치 보유 (내용은 비공개) |
| ③ | 제안 | 평가 축에 따라 우리 안 생성 |
| ④ | 비교분석 | 운영사 안과 우리 안을 같은 표기로 비교 |
| ⑤ | 검증 | 양쪽 주장 판정 — 사실 / 근거 부족 / 반박 |

## 공개되지 않는 것

회사 맥락·가중치·사례와 그 결과물은 `private/`에 두고 `.gitignore`로 제외한다. 회사명·운영사명·실제 값(IP·호스트명·계정 ID)은 `private/` 밖에 쓰지 않는다. 1차 방어는 사람이다.
